# Commercial-Data-Mining-Neural-Network
Group repo for CECS 550 Final Project. 
We have predicted one-time buyers and potential loyal customers in anonymized users' shopping logs. We have identified which target demographics shop most and when, so advertising can be directed to them at the right time. We have found that Parzen Windows is the best model for classifying data.

Please run all Python (.py) and Jupyter Notebook (.ipynb) files to see our code run.
